- 결정사항
    - 영상 생성 입력 화면은 아직 대규모 단계 구조로 옮기지 않기로 함 — 현재는 입력 화면만 존재해 미리 구조를 확장하기엔 이른 단계이며, 이후 단계 화면 추가 시 구조 이동 예정
    - 이미지 파일 형식 지원 확장(AVIF/HEIC 등)은 프론트엔드 단독으로 결정하지 않기로 함 — 백엔드 저장 정책과 AI 모델 입력 정책에 따라 달라지는 사안이라 현재는 PNG/JPG/WEBP 중심으로 제한 유지
    - 전역 404 화면은 페이지 자체는 최소 구조로 두고 실제 구현은 별도 영역에 두기로 함 — 프로젝트의 폴더 구성 관례를 따르기 위함
    - 로그인 화면도 실제 인증 연동 전이지만 입력값 검증과 제출 흐름은 미리 구현해두기로 함 — 추후 인증 방식이 정해지면 내부 로직만 교체하면 되도록 구조화
