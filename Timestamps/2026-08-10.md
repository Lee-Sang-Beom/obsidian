- [x] 배포 환경 WorkOS 로그인 redirect 오류 수정
  - 문제 상황
    - `192.168.1.21:3001` 배포 환경에서 Google 로그인 자체는 성공
    - 하지만 WorkOS callback 이후 `http://0.0.0.0:3000/studio`로 redirect되며 `ERR_ADDRESS_INVALID` 발생
    - 이후 `192.168.1.21:3001`로 직접 접속하면 로그인 상태는 유지되어 callback 인증 처리는 성공한 것으로 확인

  - 원인
    - Docker 컨테이너 내부에서 Next.js는 `0.0.0.0:3000`으로 실행됨
    - WorkOS AuthKit `handleAuth()`가 callback 이후 이동할 URL을 만들 때 공개 접속 주소가 아닌 컨테이너 내부 실행 주소를 기준으로 사용
    - 결과적으로 `/studio` 이동 주소가 `http://0.0.0.0:3000/studio`로 생성됨

  - 수정
    - `NEXT_PUBLIC_WORKOS_REDIRECT_URI`에서 공개 origin 추출
      - 예: `http://192.168.1.21:3001/auth/callback`
      - origin: `http://192.168.1.21:3001`
    - WorkOS callback route의 `handleAuth()`에 `baseURL` 명시
    - 추가 파일
      - `src/lib/auth/workos-public-base-url.ts`
    - 수정 파일
      - `src/app/auth/callback/route.ts`
