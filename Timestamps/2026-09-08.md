#### Work (프로젝트: 제주 렌터카)
---
- 프론트엔드
	- gitea 리포지토리 구성 및 연결 
    - 로그인 화면 제작
        - 사이트 접속 시 첫 화면이 로그인 페이지로 뜨도록 구성
        - 배경 이미지, 로고, 이메일/비밀번호 입력창, 로그인 상태 유지, 비밀번호 찾기 등 로그인에 필요한 화면 요소를 모두 구현
        - 향후 기능 추가가 쉽도록 화면 구성 요소를 역할별로 나누어 정리
    - 로그인 진입 애니메이션 제작
        - 자동차가 화면을 가로지르며 로그인 화면이 드러나는 인트로 애니메이션
        - 임시 아이콘 대신 제주스타 렌터카 브랜드 이미지(차량)로 교체
    - 브랜드 이미지 표현 개선
        - 로고 배치와 크기를 조정해 잘려 보이던 부분 보정
    - 로그인 이후 공통 화면 틀(레이아웃) 구축
        - 로그인 후 진입하는 모든 관리자 화면이 동일한 틀(좌측 메뉴, 상단 영역, 콘텐츠 영역)을 공유하도록 구성
        - 좌측 메뉴에 로그아웃 버튼 추가
        - 대시보드/영상 관리/운영 관리/설정으로 메뉴를 그룹핑하고, 하위 메뉴 구조까지 설계
        - 상단 경로 표시(브레드크럼) 클릭 시 해당 그룹의 첫 하위 메뉴로 이동하도록 처리

- 이슈 대응 (개발 중 발생한 문제와 해결)
    - 현재 프로젝트에 맞지 않는 이전 로그인 인증 방식(WorkOS) 관련 설정을 제거
    - 이미지 캐시 처리 방식 문제로 배포용 빌드가 실패하던 것을 수정
    - 레이아웃 구성과정에서 발생한 next-eslint/RSC 컴파일러 체크문제 (직렬화) 해결 
      
- 결정사항
    - 로그인 인증 기능(실제 계정 검증)은 아직 연결하지 않고, 화면 이동 흐름만 우선 구현함 — 인증 방식이 아직 확정되지 않았기 때문이며, 실제 보안 처리는 이후 별도 작업으로 진행 예정
    - 로그인 이후 공통 화면 틀은 로그인 화면과 분리된 별도 영역에 배치하기로 함 — 로그인 화면까지 같은 틀에 포함되면 불필요하게 메뉴/상단 영역이 함께 보이는 문제가 있어 분리
    - 메뉴 데이터는 이후 하위 메뉴가 늘어날 것을 고려해 확장 가능한 구조로 설계

- 다음 단계
    - 실제 대시보드 화면의 콘텐츠 구성과 위젯 설계
    - 로그인 기능(입력값 검증, 실제 인증)을 인증 방식 확정 후 적용
    - 이후 관리자 화면들을 만들 때 적용할 폴더/파일 구성 기준 구체화
