1. 영상 생성 과정에서의 UX 개선
 - 영상 생성 과정을 전체적으로 한번 싹 훑어보면, 특정 동작 수행 후 사용자가 다음 버튼을 눌러줘야 하는 부분이 있어. 
 - 근데 이 시스템을 잘 모르는 사용자는 현재 어디까지 진행했는지, 지금 화면에서 뭘 눌러야 하는지 모를 때가 있어. 나도 지금 잘 모르고 헷갈려 
 - 그래서 사용자가 어떤 과정상황에 처해있으면 다음으로 어떤 버튼을 눌러야하는지 UI적으로 좀 한눈에 알아볼 수 있도록 해야할 것 같아.
 - 예를 들면 영상 수정 요청 시, 수정 요청 생성 버튼 누르고 그 다음에 눌러줘야하는 문맥준비나 계
   획생성같은 버튼이 있잖아. 내가 지금 이 버튼을 눌러야 하는지에 대한 내용이 한눈에 들어오지않음. 이거 어떻게 처리할지 고민해봐야해. 다이얼로그를 띄워서 최종확인같은 느낌을 내던가 그렇게해야할 것 같아. 단순버튼 배치식으로 하니까 눈에 안들어오는 게 원인인가 싶기도 해.
 - 이거말고도 비슷한 다른 상황이 영상 생성 과정에서 정말 많아. 전체적으로 이런 상황은 검토한번 해봐야할것같아. 마침 스타일 수정을 요구하고 있으니 겸사겸사 이 작업도 진행했으면 좋겠어.
