#### Work (프로젝트: AI 검증코어 프론트엔드)
---
- 드롭된 법령관련 검증코어 프론트엔드 프로젝트를 띄워야 한다는 요구사항 발생
	- 랜딩 페이지
		- WorkOS AuthKit 기반 인증 흐름 구성 및 로그인 후 `/chat` 리다이렉트 적용
		- 프로젝트 브랜드를 `베리로(Verify + Law)`로 정리하고 랜딩 페이지에 기획 의도 반영
		- 랜딩 페이지에 스크롤 반응형 히어로 애니메이션 적용 및 법령 아이콘 전환 추가
	  
	- 채팅 페이지
		- 채팅 페이지 경로에 AI 채팅 서비스 화면 구성 및 메시지 누적 UI 구현
		- `react-hook-form`, `zod`, `react-dropzone` 기반 채팅 입력/파일 첨부 폼 구성
		- 긴 붙여넣기 텍스트를 접힌 블록으로 처리하고 미리보기/삭제/전송 후 확인 흐름 구현
		- 직접 입력, 붙여넣기 텍스트, 파일 첨부 제한 등 채팅 입력 검증 로직 정리
		- 채팅 관련 UI와 입력 로직을 컴포넌트, hook, model 단위로 분리하여 리팩터링 진행
