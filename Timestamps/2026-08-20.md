#### Work (프로젝트: 영상 제작 프로젝트)
---
- 프론트엔드
  - `/chat` 영상 제작 화면 구조 개편
    - 사용자가 이해하기 어려운 `Brief`, `브리프` 표현을 `제작안`으로 통일
    - 기존 연속 대화형 제작 화면을 백업 처리
    - 자연어 요청을 한 번 제출한 뒤 AI가 제작안을 정리하고, 사용자가 검토/승인 후 영상을 생성하는 제출형 흐름으로 변경
    - `/chat` 화면을 단계별 화면 교체 방식으로 재구성
    - 단계 구성
      - 요청
      - 제작안 검토
      - 승인
      - 생성
      - 결과

  - `/chat` 제작 단계 UI 정리
    - 모든 단계에서 현재 단계와 전체 진행 위치를 확인할 수 있도록 `Production Stage` UI 적용
    - 현재 단계 번호, 전체 단계 수, 진행률 표시 추가
    - 첫 단계에는 이전 단계가 없으므로 이전 버튼을 숨김
    - 단계 이동은 오직 `이전 단계` 버튼 하나만 제공하도록 정리
    - `요청 수정`, `Brief 검토로` 등 중복 이동 버튼 제거
