
#### Work (프로젝트: 영상 제작 프로젝트)
---
- 프론트엔드
    - 로그인 리다이렉트 주소를 사내 환경에 맞게 재설정
    - 이미지 업로드 검증 로직 보완
        - 확장자가 아닌 실제 파일 내용을 분석해 이미지 형식을 정확히 판별하도록 개선
        - 서로 다르게 표기되는 동일 이미지 형식을 표준 형식으로 통일
        - 서버 업로드 전 파일 정보를 판별 결과 기준으로 정규화
        - 빈 파일, 용량 초과(10MB), 지원 불가 형식, 손상된 이미지 사전 차단
    - 영상 생성 완료 판정 로직 보완
        - 여러 구간이 모두 성공한 경우, 최종 합쳐진 영상이 준비될 때까지 정확히 대기하도록 변경
        - 일부 구간이 취소된 경우에도 완료된 영상을 사용자에게 보여줄 수 있도록 예외 처리
        - 영상 병합 대기 상태를 사용자에게 안내하는 표시 추가
        - 병합 오류 발생 시 실패로 정상 처리되도록 개선
    - '스튜디오' 화면 구조 정리
        - '진행 중인 제작' 영역 제거
        - '제작 완료 영상' 영역만 남기도록 화면 구조 변경
        - 사용하지 않는 코드 삭제
        - 완료 영상 카드 UI를 보기 편한 갤러리 형태로 개편
        - 제목 잘림, 카드 높이 등 UI 문제 개선
        - 다운로드 버튼을 아이콘 형태로 정리
    - '스튜디오' 완료 영상 목록 불러오는 방식 개선
        - 완료된 영상만 안정적으로 불러오도록 서버 통신 방식 업데이트
        - 완료 영상 전용 데이터 처리 로직 추가
        - 화면 표시용 데이터 변환 로직 정리
        - 페이지 단위로 나눠 불러오는 페이지네이션 UI 추가
- 백엔드
    - 완료 영상 목록 조회 범위 축소
        - 기존 목록에서 진행 중인 요청을 제외하도록 변경
        - 완성된 영상만 조회되도록 API 정리
        - 실제로 영상이 정상 존재하는 요청만 완료 영상으로 반환
    - 완료 영상 목록 페이징 추가
        - 페이지 단위 조회 기능 추가
        - 전체 개수, 페이지 수 등 화면 표시에 필요한 정보 포함
        - 완료 영상 목록에서 번호 기반 페이지 이동 가능하도록 응답 구조 변경
    - 완료 영상 응답 구조 정리
        - 응답 데이터를 일관된 형식으로 정리
        - 완료 항목의 상태를 '완료'로 고정 표기
        - 완료 영상 항목에 링크, 완료 시각 등 필요한 정보 포함
    - 목록 조회 안정성 보완
        - 일부 데이터 조회 실패 시 해당 항목만 오류 처리, 나머지 목록은 정상 표시
        - 실제 영상 데이터가 없는 항목은 목록에서 자동 제외
        - 예외 케이스 테스트 갱신
    - 문서 및 테스트 갱신
        - API 명세 문서 갱신
        - 프론트엔드 연동 문서 갱신
        - 관련 테스트 코드 새 기준에 맞게 수정
