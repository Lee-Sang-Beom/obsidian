#### Work (프로젝트: 영상 제작 프로젝트)
---
- 프론트엔드
  - `/chat` 영상 생성 요청 흐름 정리
    - 기존 대화형 제작 화면 구조를 단순 제출형 영상 생성 흐름으로 정리
    - 사용자가 제작 방식 선택 후 프롬프트와 필요한 이미지를 입력하고, 최종 확인 후 생성 요청을 보내는 구조로 변경
    - 생성 방식 구분 추가
      - T2V: 텍스트만으로 영상 생성
      - I2V: 이미지 1개 기반 영상 생성
      - R2V: 참조 이미지 1~4개 기반 영상 생성
    - 영상 길이 선택값 정리
      - 15초
      - 30초
      - 1분
      - 3분

  - `/chat` 입력 및 검증 UI 개선
    - T2V 선택 시 이미지 첨부 비활성화
    - I2V 선택 시 이미지 1개만 첨부 가능하도록 제한
    - R2V 선택 시 이미지 1~4개만 첨부 가능하도록 제한
    - 이미지 파일당 최대 용량을 10MB로 제한
    - 이미지 개수 초과, 지원하지 않는 파일, 용량 초과 시 사용자 피드백 표시
    - 생성 방식 변경 시 기존 입력값, 첨부 이미지, 영상 길이 초기화 처리
