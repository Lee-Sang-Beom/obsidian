
## 1단계: 메모리 무결성 끄기

**설정 → 개인 정보 및 보안 → Windows 보안 → 장치 보안 → 코어 격리 세부 정보 → 메모리 무결성 끔**

---

## 2단계: 하이퍼바이저 비활성화

**관리자 권한 CMD**를 열고 실행합니다.

```
bcdedit /set hypervisorlaunchtype off
bcdedit /set vsmlaunchtype off
```

### 설정이 제대로 저장됐는지 확인 (중요)

```
bcdedit /enum {current}
```

출력 맨 아래에 두 줄이 모두 있어야 합니다.

```
hypervisorlaunchtype    Off
vsmlaunchtype           Off
```

> **시행착오 포인트:** 명령이 성공한 것처럼 보여도 `hypervisorlaunchtype` 줄이 목록에 없는 경우가 있었습니다. 이 상태에서는 재부팅해도 하이퍼바이저가 계속 실행됩니다. 줄이 없으면 아래처럼 다시 실행하세요.
> 
> ```
> bcdedit /set {current} hypervisorlaunchtype off  
> ```
> 
> 아래 4단계의 도구를 실행한 뒤에도 이 값이 지워질 수 있으므로, 도구 실행 후에는 반드시 다시 확인하세요.

---

## 3단계: 재부팅 후 상태 확인

BCD 설정은 **재부팅해야 반영**됩니다. 재부팅 후 관리자 CMD에서:

```
systeminfo
```

맨 아래 두 항목을 봅니다.

|항목|아직 켜져 있음 ❌|꺼짐 (성공) ✅|
|---|---|---|
|가상화 기반 보안|상태: 실행 중|상태: 사용 안 함|
|Hyper-V 요구 사항|"하이퍼바이저가 검색되었습니다…"|VM 모니터 모드 확장: 예<br>펌웨어에 가상화 사용: 예<br>두 번째 수준 주소 변환: 예<br>데이터 실행 방지 사용 가능: 예|

> "펌웨어에 가상화 사용: 예"가 보이면 BIOS의 VT-x도 이미 켜져 있다는 뜻입니다.

---

## 4단계: 그래도 안 꺼질 때 (DG Readiness Tool)

1. 아래 Microsoft 공식 페이지에서 도구를 다운로드하고 압축을 풉니다.  
    https://www.microsoft.com/en-us/download/details.aspx?id=53337
2. **관리자 PowerShell**을 열고 압축 푼 폴더로 이동합니다.
3. 아래 명령을 실행합니다. 실행 후 자동으로 재부팅됩니다.
    
    ```
    .\DG_Readiness_Tool_v3.6.ps1 -Disable -AutoReboot
    ```
    
4. **스크립트 실행이 막히면** 먼저 아래 명령을 입력하고, 확인 창에서 **예**를 선택한 뒤 다시 시도합니다.
    
    ```
    Set-ExecutionPolicy -Scope Process Bypass
    ```
    
    (현재 PowerShell 창에만 적용되며, 창을 닫으면 원래대로 돌아갑니다.)
5. 재부팅 후 **2단계의 `bcdedit /enum {current}`로 두 값이 Off인지 다시 확인**하고, 없으면 다시 설정한 뒤 재부팅합니다.

---

## 5단계: 그래도 여전히 "실행 중"일 때

|증상|원인|해결|
|---|---|---|
|`hypervisorlaunchtype` 줄이 없음|설정이 저장되지 않았거나 도구가 지움|2단계 명령 재실행 → `bcdedit /enum`으로 확인 → 재부팅|
|BCD는 Off인데 VBS가 실행 중|Windows 기능이 하이퍼바이저를 사용|`Win+R` → `optionalfeatures`에서 **Hyper-V, 가상 머신 플랫폼, Windows 하이퍼바이저 플랫폼, Windows 샌드박스, WSL** 해제 후 재부팅|
|위 방법으로도 안 꺼짐|레지스트리/정책으로 VBS 유지|아래 레지스트리 명령 실행 후 재부팅|

```
reg add "HKLM\SYSTEM\CurrentControlSet\Control\DeviceGuard" /v EnableVirtualizationBasedSecurity /t REG_DWORD /d 0 /f
reg add "HKLM\SYSTEM\CurrentControlSet\Control\DeviceGuard" /v RequirePlatformSecurityFeatures /t REG_DWORD /d 0 /f
```

그룹 정책을 쓰는 환경이라면 `gpedit.msc` → 컴퓨터 구성 → 관리 템플릿 → 시스템 → Device Guard → "가상화 기반 보안 켜기"를 **사용 안 함**으로 바꿉니다.

---

## 참고 사항

- `systeminfo`의 **"App Control for Business policy: 적용"** 은 앱 실행 제어 정책이며 가상화와는 별개라 무시해도 됩니다.
- 하이퍼바이저를 끄면 **WSL2, Docker Desktop, Windows 샌드박스**는 동작하지 않습니다.

## 다시 켜기 (원복)

1. 관리자 CMD에서 실행합니다.
    
    ```
    bcdedit /set hypervisorlaunchtype auto
    ```
    
2. 코어 격리에서 **메모리 무결성**을 켭니다.
3. 재부팅합니다.
