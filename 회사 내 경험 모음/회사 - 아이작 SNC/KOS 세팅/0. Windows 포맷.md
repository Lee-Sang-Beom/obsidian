
1. 공용 PC가 될 PC에서 아래 경로로 포맷 진행
```
설정 > 시스템 > 복구 > PC 초기화 > 모든 항목 제거 (옵션) > 로컬 다시 설치(windows 다시 설치함) > 초기화 진행
```
 
 2. 포맷 과정 및 완료 시, 공용 PC의 비밀번호는 아래와 같아야 함
```
(1) 장치명
	- ijak
(2) 계정명
	- ijak-pc
(3) 패스워드
	- dkdlwkr33## (아이작33##)
```


3. 마이크로소프트 계정 건너뛰기
	- `Shift + F10` 오픈 후 `start ms-cxh:localonly` 입력
